# Subscription Hunter: yapılacaklar

Cüzdan yeniden tasarımından sonra kalanlar. Önce sıradaki işler, sonra fikirler.

## Sıradaki (tasarım)
- [ ] Ekle formu: cüzdan diline uyarla (seçilen servisin kart önizlemesi)
- [ ] Detay sayfası: büyük kart, 12 aylık ödeme noktaları, takvim
- [ ] İstatistik: takvim ısı haritası, alan grafiği, segmentli kontrol yerine sekme çizgisi
- [ ] Onboarding: yeni logo ve kart yığını animasyonu
- [ ] Kart yığınına dokununca öne çıkma / açılma animasyonu
- [ ] Açık tema: her ekranı telefonda tek tek gözden geçir
- [ ] Ayarlar: "İletişim ve destek" başlık tekrarı, para birimi adları yerelleştirilsin (TRY · Turkish lira)

## Kontrol sonrası
- [ ] Baştan aşağı hata taraması (cihazda gerçek kullanım)
- [ ] Release APK derlemesi: GeneratedPluginRegistrant hatası (flutter clean ile geçiyor, kökü araştırılacak)
- [ ] Klasör adı Türkçe karakterli olunca AOT derleme hatası: build her zaman ASCII yoldan

## Özellik fikirleri
- [ ] Deneme süresi takibi
- [ ] Aylık bütçe ve halka
- [ ] Yıllığa geçiş önerisi
- [ ] Elle kur ile tek para biriminde toplam
- [ ] Yedekle / geri yükle
- [ ] Biyometrik kilit
- [ ] Ana ekran widget'ı
- [ ] İptal kısayolu
- [ ] Paylaşılan abonelik (kişi başı maliyet)
